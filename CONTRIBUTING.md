# Contributing

Thank you for improving MyHome.

1. Create a branch from `main`.
2. Keep the default site blank and free of personal data.
3. Do not add copyrighted images, music, characters, logos, or scraped content
   to the application or presets.
4. Add credits and source information for any permitted third-party asset.
5. Run `npm run typecheck`, `npm test`, and `npm run build`.
6. Open a pull request explaining the behavior and user impact.

Contributions and redistributed modifications remain subject to the
MyHome No-Sale Share-Alike License.
